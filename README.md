# College Portal

The College Portal is a centralized platform for students, faculty, and administrators to access important academic and campus services.

## Features

- Student and faculty portal access
- User authentication and role-based access
- Course and subject information
- Notices and announcements
- Student profile management
- Academic information dashboard
- Responsive interface for desktop and mobile devices
- Admin management capabilities
- Persistent light, dark, and system-theme preferences
- An in-app About panel with demo accounts and browser-only data notice

## Run locally

This is a static, dependency-free site. Open `index.html` in a browser, or serve the folder with any static-file server.

## Improvements

- Organized college-related information in one platform
- Simplified access to academic resources
- Improved communication between students, faculty, and administration

## Known Limitations

- This static demo has no server, real authentication, or multi-device data sync.
- Demo credentials and browser-stored records must not be used in production.
